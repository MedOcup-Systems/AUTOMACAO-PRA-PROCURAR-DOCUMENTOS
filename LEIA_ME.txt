  PRIMEIRA VEZ — INSTALACAO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PASSO 1: Instale o Python (se ainda nao tiver)
           → https://www.python.org/downloads/
           → IMPORTANTE: marque "Add Python to PATH" na instalacao

  PASSO 2: Instale o Tesseract OCR
           → https://github.com/UB-Mannheim/tesseract/wiki
           → Baixe o .exe de 64 bits e instale normalmente

  PASSO 3: Execute o arquivo INSTALAR_DEPENDENCIAS.py
           → Instala as bibliotecas Python (como PyMuPDF) automaticamente
           → Substitui arquivos .bat antigos.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  USO DO PROGRAMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Abra o programa (atalho na area de trabalho ou ABRIR_SEPARADOR_ASOs.bat)

  2. Selecione os 3 caminhos:
     • Planilha de Funcionarios: arquivo .xlsx com nomes e datas
       Coluna A = Nome do funcionario
       Coluna B = Data no formato DD/MM (ex: 06/02)

     • Pasta do Mes: pasta do mes no Drive
       Exemplo: G:\Meu Drive\NOVAMEDICINA.2\2026\2.FEVEREIRO 2026
       O programa navega automaticamente pelas subpastas de dia

     • Pasta de Saida: onde os ASOs separados serao salvos

  3. Clique em "INICIAR PROCESSAMENTO"

  4. NOVO RECURSO — CHECKPOINT E RETOMADA AUTOMATICA:
     • O sistema salva o progresso a cada ASO encontrado no arquivo:
       checkpoint_progresso.json (na pasta de saida).
     • Se o computador desligar, travar ou o programa for fechado,
       ao rodar novamente selecionando a mesma pasta de saida,
       o sistema perguntara se deseja CONTINUAR DE ONDE PAROU.
     • Ele reaproveitara todos os ASOs ja encontrados e continuara
       a busca apenas para os funcionarios restantes!

  5. Acompanhe o progresso nas barras e no log

  6. Ao final, um relatorio RELATORIO_ASOs_DD-MM-AAAA.xlsx
     sera gerado na pasta de saida com:
     - Aba "Encontrados": ASOs extraidos (identificando se vieram do checkpoint)
     - Aba "Nao Encontrados": nomes nao localizados
     - Aba "Resumo": totais e taxa de sucesso
